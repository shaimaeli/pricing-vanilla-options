Options Pricing Application

A web application for pricing European and American options using market data.

- Option pricing using the Black-Scholes model.
- Binomial CRR and trinomial Boyle trees.
- Implied volatility estimation using the Newton-Raphson method.
- Early exercise analysis for American options.
- Control variate method for pricing error correction.
- Convergence analysis of numerical methods.
